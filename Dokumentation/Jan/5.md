.env can be created in workflow with something like that

      - name: Create .env file
        run: |
          cat <<EOF > ./Backend/.env
          SECRET=${{ secrets.SECRET }}
          DATABASE_URL=${{ secrets.DATABASE_URL }}
          AWS_ACCESS_KEY_ID=${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY=${{ secrets.AWS_SECRET_ACCESS_KEY }}
          EOF

when starting the container an .env can be added

    docker run --env-file Backend/.env -p 8082:8082 kinderbuch-backend
