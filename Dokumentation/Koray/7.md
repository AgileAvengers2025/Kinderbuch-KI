## Pricing Models:

### On-Demand and Batch
In this model, you only pay for the resources actually used, without long-term commitments. For text generation models, both the processed input tokens and the generated output tokens are charged. A token consists of a few characters and represents the basic text unit that a model works with. For example, using the "Claude 3.5 Sonnet" model from Anthropic costs $0.003 per 1,000 input tokens and $0.015 per 1,000 output tokens.
[aws.amazon.com](https://aws.amazon.com)

### Provisioned Throughput
This model allows you to reserve a specific throughput capacity for a base model or a customized model to meet your application's performance requirements. In return, you commit to a specific runtime, typically 1 or 6 months. Costs vary depending on the model and desired throughput.
[aws.amazon.com](https://aws.amazon.com)

## Example Cost Calculation:

Assuming your app processes 100,000 input tokens per month and generates 50,000 output tokens with the "Claude 3.5 Sonnet" model:

- Input costs: 100,000 tokens / 1,000 * $0.003 = $0.30
- Output costs: 50,000 tokens / 1,000 * $0.015 = $0.75
- Total monthly costs: $0.30 + $0.75 = $1.05

Please note that this is a simplified estimate. Actual costs may vary depending on model choice, usage intensity, and additional features. For a more accurate calculation, it is recommended to use the AWS Pricing Calculator.

Additionally, Amazon Bedrock offers features such as Intelligent Prompt Routing and Prompt-Caching, which can help reduce costs and latency. These features can be particularly useful for increasing the efficiency of your application while reducing operating costs.
[aws.amazon.com](https://aws.amazon.com)

It is advisable to analyze the specific requirements of your application and, if necessary, speak with an AWS expert to obtain a tailored cost estimate.

## Using the Amazon Bedrock API

To use the Amazon Bedrock API for your children's book AI app, you can proceed as follows:

1. **Obtain Access to Amazon Bedrock**
    - First, ensure that your AWS account is activated for Amazon Bedrock. Bedrock may currently be limited to certain regions or available by invitation only. Make sure you have access.

2. **Access Amazon Bedrock in the AWS Management Console**
    - Go to the AWS Management Console and navigate to Amazon Bedrock. You can find it through the services search.

3. **Read the API Documentation**
    - The official API documentation provides detailed instructions for API endpoints, authentication, and SDK integration.

4. **Create API Access Keys**
    - To allow the application to interact with AWS Bedrock, you need to:
        - Configure AWS IAM roles or AWS Access/Secret Keys.
        - Set the necessary permissions for Amazon Bedrock:
            - Permission policy: AmazonBedrockFullAccess or the minimal API access rights.

5. **Call the API (Example)**
    - Here is an example using Python (via boto3 SDK):

    ```python
    import boto3

    # Create Bedrock client
    client = boto3.client('bedrock', region_name='us-east-1')

    # Start text generation (example)
    response = client.invoke_model(
        modelId='anthropic.claude-v2',
        inputText='Write a funny children's story about a talking dog.'
    )

    # Display output
    print(response['resultText'])
    ```

6. **Example for REST API Access**
    - If you want to use the API endpoints directly without an SDK:
        - Make an HTTP POST request to the Bedrock endpoint.
        - Example for an endpoint (API region specific):

        ```
        https://bedrock.<region>.amazonaws.com/invocations
        ```

        Example header:

        ```json
        {
          "Authorization": "Bearer <API-Key>",
          "Content-Type": "application/json"
        }
        ```

        Example payload:

        ```json
        {
          "modelId": "anthropic.claude-v2",
          "inputText": "Tell a story about a talking dog and a magical cat."
        }
        ```
