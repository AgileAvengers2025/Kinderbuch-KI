### **Step 1: Generate a SonarQube Token**
1. Go to **SonarQube Dashboard → My Account → Security**.
2. Generate a **new token** (e.g., `SONAR_TOKEN`).
3. Add it as a **GitHub Secret** under **Repository → Settings → Secrets → Actions**.

### **Step 2: Create `.github/workflows/sonarqube.yml`**
Add the following workflow file to your GitHub repository:

```yaml
name: SonarQube Analysis

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  sonarqube:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout Code
        uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'

      - name: Install Dependencies
        run: npm install

      - name: Run SonarQube Scanner
        env:
          SONAR_TOKEN: ${{ secrets.SONAR_TOKEN }}
        run: |
          npx sonarqube-scanner \
            -Dsonar.projectKey=NodeAuthMiddleware \
            -Dsonar.projectName="Node Auth Middleware" \
            -Dsonar.sources=. \
            -Dsonar.host.url=http://your-sonarqube-server:9000 \
            -Dsonar.login=$SONAR_TOKEN
```

### **Step 3: Push Changes to Trigger Scan**
Every push to `main` or a pull request will now trigger a **SonarQube scan**.

## **2. GitLab CI/CD Integration**
For GitLab CI/CD, add the following to your `.gitlab-ci.yml`:

```yaml
stages:
  - test
  - sonarqube

sonarqube:
  image: sonarsource/sonar-scanner-cli
  stage: sonarqube
  script:
    - sonar-scanner
      -Dsonar.projectKey=NodeAuthMiddleware
      -Dsonar.sources=.
      -Dsonar.host.url=http://your-sonarqube-server:9000
      -Dsonar.login=$SONAR_TOKEN
  only:
    - main
```

To make it work:
1. Go to **GitLab → Settings → CI/CD → Variables**.
2. Add **SONAR_TOKEN** (from SonarQube) as a **GitLab environment variable**.

## **3. Jenkins Integration**
For **Jenkins**, follow these steps:

### **Step 1: Install SonarQube Plugin**
1. Open **Jenkins Dashboard** → **Manage Jenkins** → **Plugins**.
2. Install **SonarQube Scanner**.

### **Step 2: Configure SonarQube Server**
1. Go to **Manage Jenkins** → **Configure System**.
2. Under **SonarQube Servers**, add:
   - **Server URL**: `http://your-sonarqube-server:9000`
   - **Authentication Token**: `SONAR_TOKEN`.

### **Step 3: Add a Jenkins Pipeline (`Jenkinsfile`)**
```groovy
pipeline {
    agent any

    environment {
        SONAR_TOKEN = credentials('sonarqube-token')
    }

    stages {
        stage('Checkout Code') {
            steps {
                checkout scm
            }
        }

        stage('Install Dependencies') {
            steps {
                sh 'npm install'
            }
        }

        stage('Run SonarQube Analysis') {
            steps {
                sh '''
                npx sonarqube-scanner \
                  -Dsonar.projectKey=NodeAuthMiddleware \
                  -Dsonar.sources=. \
                  -Dsonar.host.url=http://your-sonarqube-server:9000 \
                  -Dsonar.login=$SONAR_TOKEN
                '''
            }
        }
    }
}
```
In **Jenkins Credentials**, add:
- **ID:** `sonarqube-token`
- **Secret:** SonarQube Token

### **Step 4: Run the Pipeline**
Push code and trigger a Jenkins build to analyze the project with SonarQube.
